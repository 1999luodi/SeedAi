# Frontend 模块说明

`frontend/` 负责用户可视化交互与标注工作流。

## 1. 页面职责

- `index.html`：入口与功能导航
- `login.html`：登录注册
- `dataset.html`：数据集创建与列表入口
- `dataset-workspace.html`：单个数据集操作页（上传、文件查看、标注入口）
- `annotate.html`：手工标注工作台
- `detection.html`：检测结果查看
- `spectrum.html`：光谱分析

## 2. 当前核心流程

1. 进入数据集管理页创建数据集（名称、描述、类型）。
2. 创建成功后留在列表页，点击“打开”进入 `dataset-workspace.html`。
3. 在操作页上传文件（支持拖拽/选择文件/选择目录）。
4. 上传限制：最多 `1000` 个文件，单次总大小 `< 5GB`。
5. 在操作页查看已上传文件，并点击“进入标注”进入手工标注页。
6. 标注页支持目标框、分类、修改、切图自动保存。

## 3. 数据集操作页布局（dataset-workspace）

- 上半区：上传区域（拖拽区 + 文件/目录选择 + 上传进度）
- 下半区：数据区域（文件列表）
- 顶部工具：返回数据集列表、进入标注

## 4. 标注页布局

- 左栏：工具和导航（目标框/分类/修改/上一张/下一张/保存/退出）
- 中栏：图像与 Canvas 可视化（支持缩放和滚动）
- 右栏：类别管理、当前标签、文件列表（均可滚动）

## 5. 前端扩展建议

- 新页面遵循“独立 HTML + 对应 JS 模块”
- 复用统一 API 调用封装，避免散落的 fetch 逻辑
- 标注交互相关状态集中管理，避免全局变量污染
- 统一先引入 `js/api-contract.js` 与 `js/shared.js`，再引入页面脚本
- 页面接口优先通过路由键（如 `SeedAI.api.route('GET_API_DATASETS')`）获取

## 6. 与后端协作边界

- 前端不直接操作数据库
- 所有数据变更通过 API 完成
- 本地缓存仅做 UI 辅助，不作为唯一数据源
