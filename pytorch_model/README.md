# PyTorch Model 模块说明

`pytorch_model/` 负责模型推理能力，不承担业务流程编排。

## 1. 模块职责

- 模型加载
- 单图/批量推理
- 推理结果标准化输出

## 2. 目录建议

- `model.py`：模型结构/加载逻辑
- `inference.py`：推理入口
- `utils.py`：图像预处理与后处理
- `weights/`：模型权重
- `output/`：推理产物

## 3. 解耦原则

- 不直接依赖前端代码
- 不直接写入业务数据库
- 输入输出通过清晰接口定义（路径/数组/JSON）

## 4. 可扩展点

- 新模型接入：新增独立加载器，不改旧模型路径
- 新任务类型：新增独立推理函数（如分类、分割）
- 新后处理策略：放入 `utils.py`，通过配置切换

## 5. 运维建议

- 权重文件版本化管理
- 记录推理参数（阈值、输入尺寸）
- 保持接口稳定，避免影响后端调用
